# Open When You Miss Me 💌

A tiny iPhone-first anniversary website.

## Personalize it

1. Open `content.js` in Notepad or VS Code.
2. Change:
   - `girlfriendName`
   - `yourName`
   - the four `letterParagraphs`
   - `secretMessage`
3. Add your favorite photo to `assets/us.jpg`.
4. Optional: add your song to `assets/our-song.mp3`.

You do not need to touch the HTML/CSS/JS unless you want to redesign it.

## Preview locally

Double-click `index.html`. For the most accurate audio behavior, use a small local web server (for example VS Code Live Server).

## GitHub Pages

Upload `index.html`, `style.css`, `script.js`, `content.js`, the `.nojekyll` file, and the `assets` folder to the root of your repository. Then use Settings > Pages > Deploy from a branch > `main` > `/(root)`.

### Privacy note

GitHub Pages is a public website. `noindex` is included to discourage search engines, but anyone with the URL can still open it. Do not put secrets or sensitive information in it.
